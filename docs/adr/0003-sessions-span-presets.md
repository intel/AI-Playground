# Sessions span presets; context crosses presets through an append-only Session History

A Session used to be bound to one preset: switching an agent preset blanked the open session, Image Gen/Edit/Video kept a gallery instead of a history, and each preset kept its own record. A Session is now the user's unit of work and any mix of presets takes turns in it; only the New Session button starts another. Each Session owns a Session Folder holding its artifacts and `session-history.jsonl`, one History Entry appended per settled turn (preset, prompt, output). Context crosses presets through that file and nothing else: a chat or agent preset receives a templated Session Update of the entries it missed, prepended to its next prompt and capped, plus a `session_history` tool to read further; edit/video/speech-to-text presets default their input to the Session's newest matching artifact; image-generation presets read nothing. Each agent preset keeps one Harness Session per Session, so Agent → Image Gen → Agent resumes the same harness context; the exception is a Task Run, which runs inside its Session in a fresh Harness Session with no context from it. The Agent preset's workspace is the Session Folder's `files/` directory, so the paths the history hands out are files the agent can open, while the history and `session.json` sit beside it, out of reach of the agent's write tools; Game Agent and Quick Coder keep their game folder in the games library.

## Considered Options

- **One shared transcript every preset reads** — rejected: agent presets each carry their own harness context and system prompt, and media presets have no transcript at all; a shared message list would be rewritten under each harness on every switch and forfeit its KV cache.
- **An LLM-written summary of the in-between turns** — rejected: it costs a model call (and a GPU swap) per preset switch, can misstate what happened, and is not reproducible. A string template is free and exact; the tool covers the detail it leaves out.
- **Putting the Session Update in the system prompt** — rejected: it changes on every turn, which would move the prompt's divergence point to the front and forfeit the whole KV cache each step.
- **One global artifact directory** (today's `media/`) — rejected: deleting a Session could not delete its files, and the agent's workspace would be every Session's output. The gallery now reads every Session's History Entries instead of keeping its own index.
